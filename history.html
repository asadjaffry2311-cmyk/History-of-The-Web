Timeline

Key Moments in the History of the Web

The Web did not appear overnight. It grew out of decades of research into networking, protocols, and the desire to connect human knowledge across machines. This timeline traces that journey — from the first computer network in 1969 to the social and mobile Web of today.

Did you know? The very first message ever sent over a computer network was just two letters: "Lo" — sent on 29 October 1969 from ARPANET at UCLA to Stanford. The system crashed before the word "Login" could be completed. Source: DARPA

The Full Timeline

1960s – 1970s

Networks Before the Web

Long before the Web existed, researchers were already trying to connect computers to one another. The key breakthrough came on 29 October 1969, when the U.S. Defense Department's ARPANET sent its first message from UCLA to Stanford. The message was meant to be "Login" — but the system crashed after just two letters: "Lo."

ARPANET introduced the idea of packet switching — breaking data into small units that travel independently through the network and are reassembled at the destination. This was radically different from the telephone system, where a dedicated line was held open for each call. According to MDN Web Docs, ARPANET first ran the NCP protocol and later the first version of TCP/IP, making it a direct ancestor of the modern internet.

1980s

TCP/IP and the Birth of the Modern Internet

By the early 1980s, ARPANET had grown into a patchwork of different networks that could not easily talk to each other. The solution was TCP/IP, developed by Vint Cerf and Bob Kahn. On 1 January 1983 — sometimes called "Flag Day" — ARPANET switched entirely to TCP/IP, which GeeksforGeeks notes is celebrated as the official birth of the modern Internet.

TCP handles reliability: it divides data into packets, sends them, and checks that every packet arrives correctly. If a packet is lost, it is resent. IP handles routing: it gives every device a unique numerical address and finds the best path for each packet to travel. Also in the 1980s, Paul Mockapetris invented DNS, introducing domains like .com, .org, and .edu and making the internet far easier to navigate.

1989 – 1991

Tim Berners-Lee and the World Wide Web

On 12 March 1989, Tim Berners-Lee submitted a proposal at CERN titled "Information Management: A Proposal." His supervisor annotated it: "Vague but exciting." That document became the blueprint for the World Wide Web.

By Christmas 1990, Berners-Lee had built the first web browser (called WorldWideWeb), the first web server (running on his NeXT computer), and defined the three core technologies that still underpin every website today:

  • HTML — the language for writing web pages
  • HTTP — the protocol for transferring pages between server and browser
  • URLs — the addressing system that identifies every resource on the Web

On 6 August 1991, the first public website went live at info.cern.ch — it is still accessible today. According to CERN, on 30 April 1993, CERN put the Web software in the public domain — free for anyone to use. That single decision allowed the Web to become a global public resource.

1990s

Browsers and Public Access

The Web remained a tool for scientists until April 1993, when students at the University of Illinois released Mosaic — the first browser to display images and text on the same page. It was free to download and worked on Windows, Mac, and Unix. According to the National Science Foundation, within 18 months of its launch, Mosaic had over a million users and the number of websites grew from 130 in 1993 to over 100,000 by 1996.

In 1994, Mosaic co-creator Marc Andreessen co-founded Netscape Communications, releasing Netscape Navigator — the browser that brought the Web into millions of homes. That same year, Berners-Lee founded the World Wide Web Consortium (W3C) to maintain open standards for the Web — ensuring it would remain an interoperable public resource rather than a proprietary platform. By 1995, Netscape Navigator had around 10 million global users.

2000s – Today

The Dynamic, Social, and Mobile Web

The late 1990s saw a massive speculation bubble in internet companies — the dot-com bubble — which burst in 2000–2001. But the Web itself survived and evolved. Around 2004, writers and technologists began describing a new generation of the Web — often called Web 2.0 — characterised by user-generated content, social networks, and platforms such as Wikipedia (2001), Facebook (2004), YouTube (2005), and Twitter (2006).

The launch of the iPhone in 2007 transformed how people accessed the Web. For the first time, a full browser ran on a pocket-sized device, making the Web truly mobile. Today, according to DataReportal, over 6 billion people use the internet — the majority of them through a mobile device. The Web has moved from a document-sharing system to the primary infrastructure of global communication, commerce, and culture.

How the purpose and key technologies of the Web changed across three major periods.

Glossary of Key Terms

Quick definitions of every technical term used on this page. Full explanations are on the How It Works page.

Term Definition Source
ARPANET The world's first packet-switched computer network, built in 1969 by the US Defense Department MDN
TCP/IP The two foundational protocols that route data across the internet: TCP ensures reliable delivery, IP handles addressing Cloudflare
DNS Domain Name System — translates human-readable addresses like "google.com" into numerical IP addresses MDN
HTML HyperText Markup Language — the standard language for creating web pages MDN
HTTP HyperText Transfer Protocol — the rules governing how web browsers and servers exchange data MDN
URL Uniform Resource Locator — the unique address of any resource on the Web MDN
Hyperlink A clickable reference that connects one document to another, forming the basic structure of the Web Wikipedia
Web 2.0 A term for the generation of websites that allow users to create and share content, not just read it Wikipedia
