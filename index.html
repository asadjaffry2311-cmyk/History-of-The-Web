On 12 March 1989, a British scientist named Tim Berners-Lee submitted a document at CERN titled "Information Management: A Proposal." His boss labelled it "vague but exciting." That proposal became the World Wide Web — and today more than 6 billion people use it every day.

What This Site Covers

1. Historical Development

The Web grew out of decades of networked computing research, beginning with the ARPANET experiments of the 1960s. According to CERN, the Web was originally designed so that scientists across the world could automatically share information — it only became a public tool later. Each milestone introduced a key concept: hypertext, URLs, HTTP, and the browser.

2. Technical Structure

Behind every webpage is a conversation between a client and a server, governed by protocols. According to MDN Web Docs, when you type a URL, your browser asks DNS to find the correct IP address, sends an HTTP request to the web server, and receives HTML and CSS files back — all in a fraction of a second.

3. Semiotic Relevance

The Web is not only a technical system — it is a space of signs. Links structure navigation as a form of argument. Layouts guide attention and imply hierarchy. Interfaces encode assumptions about users. As Tim Berners-Lee himself wrote, the Web was designed to be a medium of human communication — which makes it a natural object of semiotic analysis.

Why This Topic Matters

The history of the Web is not simply a history of technology. It is a history of how human communication was reorganised. Before 1991, documents lived in libraries and archives — separate, static, difficult to connect. The invention of the hyperlink changed that: any document could now point to any other document, anywhere in the world. According to the World Wide Web Foundation, this single structural change rewired how knowledge is produced, stored, and shared.

At the same time, this transformation did not happen automatically. It required deliberate choices — about protocols, about open standards, and about access. Crucially, Tim Berners-Lee chose not to patent the Web. As CERN notes, in 1993 CERN put the World Wide Web software in the public domain, ensuring it could be freely used and built upon by anyone. That decision shaped everything that followed. Studying the Web means asking not just how it works, but why it was built the way it was — and what values those choices encoded.

For students of semiotics, the Web is a particularly rich object of study. The concepts used to analyse signs — structure, code, context, interpretation — apply directly to HTML, CSS, hyperlinks, and interface design. The World Wide Web Consortium (W3C), founded by Berners-Lee in 1994, continues to govern the open standards that keep the Web a shared, interoperable space. This site attempts to make that connection between technology and meaning explicit.

Key Concepts at a Glance

These are the core technical terms used throughout this site. Each is explained in more depth on the How It Works and Timeline pages. Definitions are based on MDN Web Docs Glossary.

Term What it means Why it matters
HTML HyperText Markup Language — the structure of a web page Defines what content exists and how it is organised
CSS Cascading Style Sheets — the visual style of a page Controls how content looks: colour, font, and layout
HTTP HyperText Transfer Protocol — the rules for exchanging data on the Web Governs how browsers request pages and how servers respond
DNS Domain Name System — the Web's address book Translates human-readable URLs into numeric IP addresses
TCP/IP Transmission Control Protocol / Internet Protocol Breaks data into packets and routes them across the network
URL Uniform Resource Locator — a web address Identifies the precise location of any resource on the Web
